# ProjetoC
Projeto realizado no Segundo Período da Graduação em Ciência da Computação (UEPB)

Linguagem C

O objetivo do projeto é gerir consutas e tratamentos de uma clínica.
Tipos de conta:
- Pacientes
- Médicos

Funções:
- Marcar e desmarcar consultas (esta última pode não funcionar corretamente)
- Criar, Gerir e Deletar acompanhamentos
- Alterar os dados da sua conta
